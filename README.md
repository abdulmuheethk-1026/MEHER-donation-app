# MEHER Donation App

A MERN stack–based donation website focused on four core areas:
- Poverty
- Education
- Medical Aid
- Orphanage Support

The platform includes secure authentication, allowing authorized users to add new donation campaigns or delete existing ones.

## Tech Stack
- MongoDB
- Express.js
- React.js
- Node.js

## Features
- User authentication and authorization
- Create and delete donation campaigns
- Category-based campaigns
- Responsive user interface
